# Forge

> [!NOTE]
> EdHeltzel's ICM Rails

Forge is the rails for agentic ICM workspaces you keep in `~/Developer`. It is a framework, not the product you are building.

`/forge-interview` captures answers, then **generates** a minimal ICM BASE + gated folders (no workbench/template copytree). Software rails are an optional sibling toggle with generated stubs — not the default deliverable.
